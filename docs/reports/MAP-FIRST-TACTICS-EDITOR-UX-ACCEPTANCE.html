Acceptance verdict

Ready for a serious owner playtest

The editor no longer asks the player to mentally combine a sheet overview, a parallel wizard, and a map. Editing a Tactic now opens one focused map workspace with its phase spine, Group placement, behavior, conditions, and bot-specific tools close to the ground they affect.

This is not a declaration that authoring is finished. It means the interface is finally coherent enough that the next useful evidence should come from making real strategies—not another speculative full redesign.

13/14review themes addressed

The remaining theme is hands-on feel and simplification after real use.

What the acceptance pass changed

One editor

Classic mode and the layout switch are gone. Map-first is the sole player-facing editor over the existing document and controls.

Focused tactic workspace

Opening a Tactic replaces the Sheet overview instead of compressing the map beside duplicated squad and save UI.

Start from useful defaults

Complete squads are allocated into recipe Groups immediately. A blank one-Group Tactic starts with the team available to place.

Native map vocabulary

New visible recipes produce ordinary Posts and Patrols. Loaded Area or Converge jobs remain compatible and offer explicit conversion.

Map-local undo

Visible Undo/Redo covers the in-progress Tactic. Draw and drag gestures are grouped, and cancel restores the prior geometry.

Direct phase spine

Phases select in one click, have explicit edit actions, scroll affordances, and a named Finish boundary rather than an anonymous final arrow.

Behavior beside the map

Destination posture, travel response, and recovery form a readable rail adjacent to the map, with the selected Group clearly named.

Progressive conditions

Configured rows are shown first. Requirements, triggers, exceptions, and alternatives are added through categorized pickers instead of duplicate full catalogs.

One-click context switching

Selecting another phase, transition, Group, or bot changes the contextual editor immediately. Clicking empty ground still closes it.

Honest bot inspector

Attack and vision use tiles and clear labels; zero proximity vision disappears. Signature scope names the relevant class within its Group.

What remains honestly open

Needs player evidence

Authoring feel

Formation dragging, facing refinement, route editing, and complex phase transitions need sustained use by the owner. Automated coverage proves behavior, not delight.

Next design pass

Signature ergonomics

The inspector is clearer, but conservative smart defaults and map-authored Prefer/Only policies are not yet complete for all sixteen classes.

Tune after use

Condition density

Progressive disclosure is in place. Real sheets should determine which condition choices can be renamed, preset, or hidden further.

Deliberate boundary

Legacy geometry

Old Area/Converge assignments remain visible and executable. Conversion is explicit because silent migration would rewrite player intent.

The next useful test

Use the rebuilt app rather than this report as the judge:

  1. Create a blank Tactic and place the full team without opening raw membership or schema controls.
  2. Add a second phase, carry the formation forward, move a subset, and verify Undo/Redo feels trustworthy.
  3. Author a transition using one trigger plus one requirement and check whether the sentence matches the intended play.
  4. Select a bot, inspect its ranges, add a route or signature mark, then return to Group behavior without losing spatial context.
  5. Run Practice, identify one wrong behavior, and measure how quickly the map can be edited to correct it.
Decision rule: if those five actions feel comprehensible, iterate from play evidence. If they still require understanding the compiler, simplify the visible presets again—but keep the now-coherent map workspace.
