A replay is a record, not a video

The arena below is a real frame from the 2.5D renderer — bastion-01, tick 30, Pincer gen-10 against Bastille gen-5, a bolt in flight and the damage glow on a bot at one hit from dead. The renderer is not what needs redesigning. Everything around it is: the header is a debug string, the bot cards are a status dump, the event feed is an undifferentiated list, and the timeline is a bare slider.

The idea the chrome is missing is the one thing this game has that a video does not. Every match is deterministic, hashed, and exactly indexable. So the timeline becomes the spine: events are marks on it, the feed is an index into it, and selecting a bot filters both. “Watch 39 ticks” turns into “jump to the four moments that mattered”, and the shape of the fight is visible before you press play.

The chrome cannot assume a dark arena

gallery-01 is nearly white. Overlays, the tick badge and the end card all sit over the arena, so each needs its own contrast — a translucent dark panel disappears on this map. Either they move off the arena, or they carry a scrim.

Full screen — the chrome moves into the letterbox

This is the case the current viewer answers weakest, and it is the one people will spend the most time in. Today the transport floats over the arena, dims to nothing after 2.8 seconds of playback, and comes back on any touch. That is a reasonable answer to the wrong question. A phone in landscape is about 2.17:1 and the arena is 16:10, so roughly a quarter of the screen is already letterbox — space the app owns and is currently painting black.

Put the chrome there and three problems disappear at once: nothing is ever drawn over the game, so nothing has to fade and the auto-hide can go; the controls sit on the app's own ground rather than on an arena whose theme might be nearly white; and the timeline gets the full width of the frame, which is where it is most useful, because there is no event index to reach for.

When there is no letterboxA tablet at 4:3 is narrower than the arena, so the bars vanish. Below about 80px a side, fall back to an overlay — but a gradient scrim down to the field colour, never a translucent panel, because on frost-relay a dark panel disappears into a white arena.
What never hidesThe tick and both health bars. If the chrome can fade to nothing you can no longer tell who is winning, which is the one thing a spectator needs. Everything else may go to zero; those two go to 40%.
ExitUnchanged, and it was right: on a phone the way out is turning the device, because a button would be overruled by the hardware the moment they disagreed. Pointer devices keep the button, top-right of the bar.
TargetsPlay/pause is 52px, the speed chip 32px, both inside the bar and away from the screen edge where a landscape grip already sits.
Top and bottomEverything you read sits at the top of a bar; everything you press sits at the bottom. In landscape both thumbs are in the bottom corners, so information placed there is information under a hand.
HeaderWho is fighting and what it counted for, as two identity chips. The seed, rules version and hash move into Verify — they matter, but they are provenance, not a headline.
TimelineOne lane per bot, marks in that bot's accent: a hairline for a shot, a notch for a hit taken, a block for a destruction. The lane shape is the match summary.
Bot cardHealth as segments, cooldown as a draining bar, and one plain sentence for what it is doing. Not ♥♥♥ · CD 0 · ⬢ idle · → wait, which is four encodings of the same idea.
IndexThe feed is a seek control. Newest first, grouped by tick, each row jumps. Filter to the selected bot rather than scrolling past the other one.
Renderer2.5D is a remembered preference, not a header toggle — and it needs a name a player recognizes, not a dimension count.
ImmersiveUnchanged. Landscape is the trigger on a phone, the transport floats, and the timeline marks come with it — they are more useful there, not less.

2 · First run — the screen that decides whether anyone ever ships a bot

A signed-in account with no bots is the highest-leverage empty state in the product, and it is the one hand-off from the website to the CLI. It is genuinely a sequence, so it is genuinely numbered — and the last step is not “read the docs”, it is a live indicator that turns over the moment the server sees your first artifact.

What you actually write

public sealed class MyBot : IBot
{
  public BotAction Tick(BotContext ctx)
  {
    var enemies = ctx.VisibleEnemies;
    if (enemies.Count > 0 && ctx.CanShoot)
      return Actions.Shoot();

    return ctx.IsWallAhead()
      ? Actions.TurnRight()
      : Actions.MoveForward();
  }
}

The real template is a little longer — it remembers what it has seen between ticks, because fields persist for the whole match. Showing the code is the argument; a paragraph about C# is not.

Syntax colour is deliberately absent. In this system colour means a player chose it, so code separates by weight instead.

3 · The CLI — the primary building surface, and the one nobody designs

Most of the work happens here, which makes terminal output a designed surface with the same rules as any other: one column of verbs, values aligned so a change is visible between runs, colour reserved for state, and a failure that prints the fix rather than a stack trace.

AlignmentVerb column fixed width, values in the same place every run, so a diff between two runs is visible without reading.
ColourOnly state: green for a pass, red for a stop, dim for anything the machine is telling itself. Never for decoration, and never the only signal.
FailureWhat broke, on which line, and the change that fixes it. A compiler error is a design surface — it is the most-read text in the product.
SymmetryEvery noun the CLI prints is a noun the website uses. generation, placement, ranked — one vocabulary or two products.

Also worth a pass, lower priority

The appearance editor, because the whole colour policy rests on it: it currently offers a raw <input type="color">, which is why any accent is possible and why none can be reserved. It should show the pick where it will actually be seen — on a ladder row, on a bot card, and as the ring on the identity chip — and it should refuse contrast it cannot fix. The watch feed is the other one: it is a list of matches today, and it is the only place a spectator ever arrives without already knowing what they came for.
