Workshop chronology (deterministic, documented)

  • Evaluation runs inside ApplyJointTick after movement, attacks, damage, destructions and after-combat signatures; the session supplies per-tick moved/displaced, combat-acting and damaged actor sets.
  • The arrival tick never qualifies (arrival is a move). Unlock tick 25 doubles as the first qualifying tick. Completion tick C ⇒ publicly Ready again at C+1+45.
  • Channel identity is team+slot+life: death, respawn or rejoining never inherits progress; no cross-team aliasing.
  • Proven cadence at seed after seed: sessions 26→40, 86→100, 146→160 … every 60 ticks; 8/8 sessions per protected match; the dormancy boundary exact on every completion.
  • Fog narrowing deliberately preserves Workshop state — it is a public neutral-objective signal; nothing else leaks.

The replay contract marked the strike lock optional only for windup attacks; the smart Rail's heading-only full-lane declaration (the pinned v32 scene behavior) failed on signature strikes. The documented rule — “UnitTarget is a lock, not a required aiming argument” — now applies to signature strikes too. The mind keeps unlocked declarations, and the mirror bytes stayed identical to the pinned receipt.
  • The stage command dropped Workshop rules in its mode copy — the new binding-coverage validator caught it immediately.
