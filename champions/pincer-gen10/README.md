# Pincer gen-10 — the first territorial skill-shot champion

Crowned 2026-07-24 as rules-0.5 launched. Pincer led the four-doctrine native
territorial holdout at 45-9-0: 45 of 106 decided wins (42.5%). It also went
31-4-1 against the unchanged Bastille and Helix historical sentinels.

The original holdout had pre-registered a 35% leader-share ceiling, so that
run remains recorded as a gate failure. The product owner subsequently judged
42.5% to be a healthy champion share in a four-doctrine field, changed the
future ceiling to 45%, and promoted the otherwise fully passing frozen rules
and artifact in DECISIONS #75.

**Doctrine — territorial pincer.** Pincer enters the objective aggressively,
uses body position to remove refuge tiles, and programs curved projectiles to
fork the opponent's likely escape lanes. It keeps moving, turning, and firing
while scoring as sole occupant rather than paying a Wait tax. Across the
native field it combined the strongest record with fast, damage-heavy,
non-repetitive replays.
