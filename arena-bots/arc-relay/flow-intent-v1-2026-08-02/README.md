# Arc Relay Flow Intent V1

Evaluation-grade participant executor derived from `balance-audit-v2-2026-08-01`.
It keeps the frozen sheet grammar and all authored doctrine data unchanged, but
adds deterministic allied return-lane yielding so a screen or escort cannot
indefinitely block a Core carrier from its own reactor. Once committed to a
terrain-shortest return step during a detected non-progress orbit, a carrier
waits for transient traffic instead of oscillating into an equally distant
lateral detour. The commitment is bounded so a persistent reservation can
still be routed around; ordinary approach and combat movement are unchanged.

This is participant behavior, not an Arc Relay rule or map change. The paired
`arc-relay-felt-degeneracy-bars-v3` scorecard measures home-carrier progress
independently of exact tile stationarity so short orbits and allied handoffs do
not hide the failure mode.
