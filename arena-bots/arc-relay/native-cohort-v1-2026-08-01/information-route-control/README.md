# Information Route Control

Doctrine cell D asks whether information and geometry control can open real
Core deliveries. This mind treats every loose Core and return as a routing
problem whose costs change with currently observed enemies, projectiles,
hostile smoke, fields, nodes, sentries, and blocks. Friendly flare and smoke
coverage reduce the cost of a return lane. A safer lane can therefore replace
the shortest lane during the run instead of being chosen once at spawn.

Signatures are conditional. Lanterns flare an outstanding but unseen Core or a
visible enemy carrier. Veils smoke only around a threatened friendly carrier.
Hush suppresses a carrier or hostile signature contest near a Core, and Mason
blocks a carrier line. Relay uses Arc Toss only when a legal landing makes
meaningful progress toward the observed own reactor. Guns prioritize visible
hostile carriers and then bodies contesting a loose Core. The Minesmith's
authored live-route Trip Node branch is mechanically contained in this revision
because persistent nodes made the controlled replay pre-state check abort; the
archived revisions and `DX.md` preserve that evidence.

The eight-slot composition is:

1. Lantern — `pathfinder-north`
2. Lantern — `pathfinder-south`
3. Veil — `smoke-screen-north`
4. Veil — `smoke-screen-south`
5. Minesmith — `route-miner`
6. Hush — `suppression-anchor`
7. Mason — `gate-builder`
8. Relay — `core-runner`

There are six distinct classes and no class appears more than twice. Role tags
are derived once from the participant's contract topology and remain stable
across deaths and either mirrored team assignment.
