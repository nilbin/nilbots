# Frontline Labs baseline v2

This is an explicitly post-reveal remediation cohort. It is not a continuation
of the blinded baseline-v1 tournament.

- Adapter is a preserved, doctrine-compatible runtime remediation authored
  after v1 results were revealed.
- Pressure, Fabricator, and Bastion retain their exact v1 strategy source.
  Their copies exist so the corrected generic action masks and SDK/Guest
  0.10.2 bytes can be tested without overwriting any v1 artifact.
- Every build and replay remains WASM. The tournament uses two deterministic
  seeds with mirrored assignments: 24 matches rather than v1's 36.
- Numeric rules, map geometry, and playlist fingerprints remain unchanged.

This cohort answers whether framework repairs make the existing doctrines
runnable and watchable enough to support a later numeric balance arm. It
cannot erase or replace the v1 diagnostic evidence.

SDK 0.10.1 was an interim framework rebuild. The first short smoke exposed a
second SDK decoder mismatch for privacy-redacted enemy transition spawns.
SDK 0.10.2 is therefore the final cohort toolchain; the 0.10.1 hashes remain
recorded in entrant manifests as historical evidence.
