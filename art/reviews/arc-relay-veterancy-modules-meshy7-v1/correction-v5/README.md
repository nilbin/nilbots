# Motion-safe split-diadem concept

Status: **owner review candidate; conceptual art only**.

This correction replaces the center-prong floating crown with a bilateral split
crown. The left and right ornament halves never join across the chassis
centerline, so one permanent vertical Core corridor stays empty through every
veterancy level.

- `motion-safe-split-diadem-rank-1-5-clean.png` is the game-facing beauty sheet.
- `motion-safe-split-diadem-rank-1-5-clearance.png` shows the same ranks with a
  translucent diagnostic capsule and one carried-position Core.

The persistent progression is:

1. two separated rear-quarter arc segments;
2. one slim feather per side;
3. the paired crown grows inward-height and outward-width without entering the
   center corridor;
4. the paired fans become broader and more authoritative; and
5. three feather-prongs per side form a full winged command crown around an
   open center notch.

The diagnostic capsule is not proposed runtime art. It records a design
constraint for pickup, carry bob, drop, handoff, and toss presentation: no
ornament geometry may enter the swept Core lane. Core animation changes are
owned separately; this ornament should not need to hide, open, snap, or recolour
during those animations.

No Meshy credits or runtime changes were used for this concept.
