# Arc Relay veterancy modules — Meshy 7 pilot review

This directory holds static owner-review evidence for the five-part Crowned
Mantle kit described by
[`MESHY-7-HANDOFF-PLAN.md`](../veterancy-power-concepts-v1/MESHY-7-HANDOFF-PLAN.md).

The current scope is Gate A plus one Gate B provider pilot:

- `gate-a-inputs.png` shows the five coherent four-view input sets.
- `gate-a-inputs-phone.png` is the same evidence scaled for a phone.
- `gate-a-input-metrics.json` records every separate input path, dimension,
  byte size, root intent, and SHA-256 hash.
- Provider and static fit evidence is added here after the swept-blade task.
- `ASSESSMENT.md` records the Gate B verdict, facing correction, passes, and
  caveats.
- `index.html` is the phone-friendly static review gallery.

The 2x2 source sheets are review/provenance artifacts only. Meshy receives four
separate PNG files for the selected module. No model in this directory is a
runtime asset, and this pilot does not authorize generation of the remaining
four modules.
