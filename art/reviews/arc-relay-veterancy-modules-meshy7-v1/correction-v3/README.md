# Universal floating-diadem concept

Status: **owner review candidate; conceptual art only**.

`floating-diadem-rank-1-5-concept-v2.png` explores one shared veterancy treatment
for all sixteen Arc Relay bots. The same lightweight ornament floats above the
chassis rather than mounting through class-specific attachment profiles.

V2 removes the fixed rusty-orange nose panels inherited from the chassis
reference because orange is a semantic team color. The first generated concept
is retained beside it as provenance, not as the review candidate.

The persistent progression is:

1. small broken halo;
2. one center prong;
3. center plus inner pair;
4. five prongs with the outer pair folded low;
5. full lifted and spread five-prong mechanical crown.

The ornament remains an open matte brass/graphite diadem with restrained pale
gold seams. It is not a floor ring, selection marker, team-color cue, weapon,
or active signature effect. No Meshy credits were used for this concept.

Before any model generation, owner review should decide the ornament's air
gap, maximum width, and whether the level-five crown is sufficiently compact
for the health-pip region and gameplay camera.
