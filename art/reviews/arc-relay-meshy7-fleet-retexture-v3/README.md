# Arc Relay Meshy 7 multiview V3 review

`fixed-orientation-sheet.png` shows all sixteen classes with the same
front-right three-quarter camera. Every normalized chassis faces +X.

Kestrel and Palisade are the previously approved material results. The other
fourteen use the brighter ordered-multiview V3 pass plus the documented 0.65
review-tier roughness floor. The owner approved this fleet for the web runtime.
The matching GLBs were promoted byte-for-byte without another optimization
pass, and `top-down-east-icons-sheet.png` records the replacement Canvas/UI
icons rendered from those exact models.

`orientation-evidence.json` pins the source audit, model hashes, camera, and
individual capture hashes used to compose the sheet.

`top-down-east-icons.json` pins the strict orthographic top-down camera, the
192 px transparent sprites, and the narrow renderer-owned team masks. Every
normalized +X front maps to screen-right/east.
