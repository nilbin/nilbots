Outgoing reference

What this round replaces

The existing Trip Node is glossy, generic graphite hardware and too mechanically dense beside the matte fleet. The existing Sentinel is a beige bunker turret with a long gun. Both read as assets from a different family; the new concepts preserve their gameplay identities while adopting their parent classes’ materials and proportions.

Exact prompts, ordered references, dimensions and SHA-256 hashes are stored beside this sheet in PROMPTS.md and manifest.json. No game files or runtime manifests changed.
