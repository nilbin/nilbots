# Arc Relay apex forms concept v1

Status: owner-review candidate. This sheet is art direction only; it does not
change the runtime class looks or approve a Meshy generation pass.

`apex-forms-concept-v1.png` proposes one complete level-5 chassis evolution for
each of Arc Relay's sixteen launch classes. The generated sheet uses the current
approved Meshy 7 V3 fleet as its identity reference and the strict top-down
runtime icons as its gameplay-planform reference. It deliberately avoids the
retired shared crown/halo direction: every apex read comes from class-specific
signature hardware and a changed whole-body silhouette.

The fixed four-by-four order remains:

2. Palisade
3. Towline
4. Patchbay
5. Lantern
6. Mortar
7. Minesmith
8. Hush
9. Relay
10. Switchback

15. Veil
16. Nest

## Review contract

- Every chassis remains a compact levitating machine with no legs or visible
  ground-contact locomotion.
- The current class planform and muted material family remain recognizable.
- Each class receives one large signature-readable silhouette change rather
  than a shared ornament.
- A standard attack may charge and release through an integrated forward beam
  aperture; no class receives a conventional gun.
- Central height and footprint stay restrained so a carried Core, health UI,
  nearby bodies, and one-tile collision semantics remain visually plausible.
- Fixed paint and emission avoid teal and orange because those remain semantic
  team colours.
- Surfaces remain matte, light-to-mid value, and readable on the dark arena.

`apex-forms-gameplay-scale-v1.png` reduces the complete sheet to 372 by 420
pixels. At that size each bot occupies roughly the intended 40–70 pixel match
footprint, making the silhouette check more honest than the full-size render.
