robots in a perfectly aligned four-column by four-row grid. Each cell contains

three-quarter view, facing East/right, on the same flat seamless light-neutral
gray background. Use thin clean white divider lines between cells. Put one
short, correctly spelled uppercase class label centered at the bottom of each
cell. No other text.
