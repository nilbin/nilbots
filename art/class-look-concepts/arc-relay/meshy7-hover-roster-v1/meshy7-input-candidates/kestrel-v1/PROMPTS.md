# Kestrel v1 multiview generation prompts

All images were produced with the built-in image-generation workflow. The
prompts below are preserved verbatim. The first prompt produced an overhead
view despite requesting front; that image became construction evidence only.
The first rear attempt is also preserved because its body proportions failed
the cross-view gate.
