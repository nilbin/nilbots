# Generated wall-material source prompts

All four sources were generated with the built-in image-generation tool. The
images are art-direction inputs; `scripts/build-theme-art.py` is the
deterministic production step.

## Control Room / perimeter

```text
Use case: stylized-concept
Asset type: seamless source material for a top-down 2D arena wall-baking pipeline
Primary request: create a richly detailed dark industrial control-room perimeter bulkhead surface material, intended for fortified outer arena walls
Scene/backdrop: the material fills the entire square image edge to edge
Style/medium: polished stylized game texture, high-end hand-painted PBR albedo source, readable at small scale
Composition/framing: strict orthographic top-down flat material swatch; evenly distributed large steel plates, inset armor panels, restrained mechanical joints and occasional tiny bolt details; all features continue naturally through the image boundaries so it can tile
Lighting/mood: neutral flat albedo-like illumination; no cast shadows, no directional scene lighting, no bevel silhouette
Color palette: charcoal graphite, gunmetal blue, subtle muted cyan oxidation accents, very restrained amber hazard paint flecks
Materials/textures: worn painted steel, scuffs, panel-to-panel material variation, fine scratches, grime in shallow seams
Constraints: square seamless tileable texture; no standalone wall object; no outer border; no frame; no perspective; no empty background; no letters, numerals, logos, watermark, or readable signage; material only
Avoid: giant repeated square tiles, obvious checkerboard, thick black outlines, dramatic shadows, glowing UI elements, isolated props
```
